# Maintainers

Website.Tools is a **personal, solo-maintained project**.

## Sole Maintainer

| Maintainer | GitHub | Role | Scope |
|-----------|--------|------|-------|
| roddavinod99 | [@roddavinod99](https://github.com/roddavinod99) | Owner & Sole Maintainer | All areas |

There are **no additional maintainers**. Decisions, review, and release
ownership rest solely with the owner.

## Responsibilities

The sole maintainer is responsible for:

- Triage and handling of issues
- Review and merge of any invited changes
- The release process (see [RELEASE.md](RELEASE.md))
- Handling vulnerability reports per [SECURITY.md](SECURITY.md)
- Maintaining the tool registry (`src/lib/data/`) and validating changes
  against the Definition of Done in [AGENTS.md](AGENTS.md)
- Enforcing the [Code of Conduct](CODE_OF_CONDUCT.md) where applicable

## Governance

This project is ad-funded and not revenue-shared (see
[CONTRIBUTING.md](CONTRIBUTING.md)). The Owner & Sole Maintainer has final
authority over all decisions.
