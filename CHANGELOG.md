# Changelog

## [1.14.0] - 2026-09-05

### Visual redesign — Crisp Modern Minimal

The site is now a monochrome, Electric-Blue-accented, Geist-typed design system. Replaces the GitHub-Primer-flavored system across every page, every primitive, and every chrome surface. Tool behavior is unchanged; this is a CSS + asset + typography refactor.

### Added

- New design tokens: `--color-bg`, `--color-surface`, `--color-surface-2`, `--color-border`, `--color-text`, `--color-text-muted`, `--color-accent`, `--color-accent-hover`, `--color-accent-soft`, `--color-success/warning/danger` (light + dark variants hand-tuned).
- Geist Sans + Geist Mono loaded via `next/font/google` (self-hosted woff2, `display: swap`, preloaded).
- Five new SVG brand assets: `public/logomark.svg` (standalone D|I monogram), `public/favicon.svg` (accent tile), `public/logo-light.svg` / `public/logo-dark.svg` (wordmarks), `public/og.svg` (1200×630 social card).
- New `<Logomark size="sm" | "md" | "lg">` and `<Wordmark>` components in `src/components/ui/logomark.tsx`.
- 18 new visual-regression snapshots (9 pages × light + dark) at `tests/snapshots/redesign/`, generated by `tests/visual/redesign.spec.ts`.

### Changed

- `src/styles/globals.css` rewritten end-to-end (1045 → 1225 lines): 4-axis color system replaces the 5+ axis Primer-clone. Old token names preserved as backwards-compat aliases so the 230+ tool components did not need to change.
- 12 UI primitives in `src/components/ui/*` restyled (Button, Card, Badge, Tabs, Tooltip, ToolCard, ToolHeader, ToolGridSection, TryExamples, AdvancedOptions, OptionPanel, Input). New `subtle` Button variant. **Public API preserved.**
- Layout chrome (Header, Footer, SearchOverlay, ShortcutsModal) restyled: sticky blurred header, logomark+wordmark+badge composition, surface-2 footer, surface modals.
- 15 home files (hero, tool-search, 13 sections) restyled with eyebrow + display heading + optional CTA + grid pattern. Trust badges on home remain. Section-level `aria-labelledby` added.
- 10 listing/search/converter pages restyled: filter bars in surface-2 cards, tool grids in `mt-6 grid gap-4 sm:grid-cols-2 lg:grid-cols-3`, no pagination controls (static grids).
- 32 static/legal/blog/guides/workflow pages restyled: `<article className="prose">` wrapper, accent-underlined `<h1>`, table styles via the new `prose` rules. Form fields use the restyled `<Input>`, submit buttons the restyled `<Button variant="primary">`.
- `src/app/tools/[slug]/tool-client.tsx` (767 lines) restyled: trust badges moved to right column on `lg+`, content sections wrapped in surface-2 cards, action bar in ghost buttons, related tools in the new `<ToolCard>`.
- `src/components/ads/ad-container.tsx` placeholder label restyled. **`min-height` reservation preserved byte-identical** to prevent ad-driven CLS.
- Geometry collapsed from 8 radius tiers to 4 (`sm: 4px`, `md: 6px`, `lg: 8px`, `full: 9999px`). Shadows lightened ~40%. Borders are the primary depth cue.
- Motion tightened: `--transition-slow`, `--transition-slower`, `--ease-spring` removed. `card-interactive` no longer `translateY` on hover.
- Typographic rhythm tightened: leading 1.15/1.3/1.5/1.6.

### Infrastructure

- `.agents/` added to `.gitignore` (skills live in global opencode install; never tracked in this repo).
- Bundle size: **5,384,185 bytes (5.13 MB) — +1,726 bytes (+0.03%) vs pre-redesign baseline** of 5,382,459 bytes. No regression.

### Notes

- Light + dark themes hand-tuned; not auto-inverted.
- No new dependencies. Pure Tailwind v4 + `next/font`.
- `prefers-reduced-motion` rule preserved.
- AdSense `min-height` reservation preserved. CSP unchanged. Performance budget unchanged.

## [Unreleased]

### Changed

- **Sitemap submitter rewritten to match the official IndexNow spec
  (https://www.indexnow.org/documentation).** Now extracts every `<loc>` from
  `/sitemap.xml` and POSTs the full URL list to the single aggregator at
  `https://api.indexnow.org/indexnow` in batches of up to 10,000 URLs. The
  aggregator automatically shares submissions with Bing, Yandex, Seznam,
  Naver, Amazon, and Yep — submitting to each engine separately was
  duplicate work that risked 429s.
- Submitter now verifies the `/{KEY}.txt` ownership file is reachable and
  matches `INDEXNOW_KEY` before posting, so a missing or wrong key fails
  fast locally instead of returning HTTP 422 from the aggregator.
- Submitter state (`data/sitemap-state.json`) is now configurable via
  `SITEMAP_STATE_PATH`. The deploy workflow sets it to
  `/var/www/tools/data/sitemap-state.json` so the hash/skip window survives
  `git reset --hard` between deploys.
- Deploy workflow now exports `INDEXNOW_KEY` from GitHub Secrets into the
  generated `.env` so IndexNow submissions actually run on each deploy.
- `.env.example` documents both `INDEXNOW_KEY` and `SITEMAP_STATE_PATH`.
- `scripts/indexnow-submit.ts` is now a thin shim that spawns the canonical
  `.mjs` submitter with an ephemeral state file, so ad-hoc runs don't
  disturb the host's persistent state.
- Cleaner skip-decision log lines and proper handling of the "never
  submitted" case.
- Removed the dead `SEARCH_ENGINES` fallback array (Bing/Yandex pings
  are deprecated, and IndexNow already covers them).
